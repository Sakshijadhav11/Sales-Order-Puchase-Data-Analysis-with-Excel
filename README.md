# Sales-Order-Puchase-Data-Analysis-with-Excel

1. I have done the data analysis by creating a dynamic Bike Sales Dashboard that allowes stakeholders to quickly identify the profile of a successful customer. I needed a way to make the data interactive so management could filter findings without needing to know how to use Pivot Tables themselves.

2. I implemented Slicers to act as a user-friendly interface. Specifically, I used a 'Purchased Bike' slicer as a global filter. To ensure a seamless experience, I used Report Connections to link that single slicer to multiple Pivot Tables (Income, Age, and Commute Distance). This meant that one click would update the entire visual story simultaneously.

3. "By clicking 'Yes' on the slicer, the dashboard immediately reveals the 'Buyer Profile.' For example, we can see that our buyers are concentrated in the Middle Age bracket and tend to have a commute of 0-1 miles. This allows the marketing team to target their ad spend much more effectively than looking at a static spreadsheet."
